# 💧 HydroFlow — Water Reminder App (یادآور هوشمند آب)

> یک اپلیکیشن کامل React Native و TypeScript پیاده‌سازی شده با اصول **Clean Architecture** و الگوی **MVVM**، همراه با پشتیبانی دوزبانه (فارسی و انگلیسی با RTL کامل) و سوئیت کامل تست‌های **Unit Test**، **Integration Test** و **BDD (Behavior-Driven Development)**.

---

## 🌟 قابلیت‌های اصلی

- ⏰ **تنظیم هوشمند یادآور**: تعیین تعداد لیوان آب روزانه و بازه زمانی بیداری (مثلاً از ۰۸:۰۰ تا ۲۲:۰۰).
- 📐 **محاسبه خودکار فواصل**: تقسیم دقیق و ریاضی زمان‌ها در طول روز بر اساس تعداد لیوان‌ها و نمایش پیش‌نمایش زنده.
- 🔔 **ارسال نوتیفیکیشن‌های بومی**: تنظیم آلارم‌های دوره‌ای روزانه با استفاده از `expo-notifications`.
- 📊 **پایش و ردگیری روزانه**: نمودار حلقوی پیشرفت، گرید تصویری لیوان‌های نوشیده شده، ثبت سریع و قابلیت لغو (Undo) یا بازنشانی (Reset).
- 🌐 **دوزبانه کامل (فارسی و انگلیسی)**: همراه با راست‌چین خودکار (RTL) و تبدیل هوشمند اعداد به ارقام فارسی (۰-۹).
- 📚 **راهنمای یادگیری درون‌برنامه‌ای**: صفحه اختصاصی آموزش مفاهیم React Native، معماری تمیز و MVVM برای علاقه‌مندانی که تازه می‌خواهند ری‌اکت نیتیو را یاد بگیرند.

---

## 🛠️ معماری نرم‌افزار

پروژه به ۳ لایه کاملاً مجزا طبق اصول **Clean Architecture** تقسیم شده است:
1. **Domain Layer**: منطق خالص کسب‌وکار بدون هیچ وابستگی به ری‌اکت یا پکیج‌های جانبی.
2. **Data Layer**: پیاده‌سازی دسترسی به حافظه محلی (`AsyncStorage`) و سرویس نوتیفیکیشن (`ExpoNotifications`).
3. **Presentation Layer (MVVM)**: جداسازی کامل State و منطق صفحه در **ViewModel Hook**ها و المان‌های خالص تصویری در کامپوننت‌های **View**.

برای مطالعه جزییات و دیاگرام‌های معماری به [ARCHITECTURE.md](file:///f:/mohammadjavad/native/water-reminder/ARCHITECTURE.md) و برای آموزش کامل از صفر به [LEARNING_GUIDE.md](file:///f:/mohammadjavad/native/water-reminder/LEARNING_GUIDE.md) مراجعه فرمایید.

## 🧪 تست‌های نرم‌افزار

پروژه دارای ۳ لایه تست جامع و خودکار با **Jest** و **Jest-Cucumber** است:

```bash
# اجرای کلیه تست‌ها (۳۷ تست موفق)
npm test

# اجرای تست‌های واحد (Unit Tests)
npm run test:unit

# اجرای تست‌های یکپارچگی (Integration Tests)
npm run test:integration

# اجرای تست‌های رفتارمحور بر اساس فایل‌های Gherkin (BDD Tests)
npm run test:bdd

# گزارش درصد پوشش کد (Coverage Report)
npm run test:coverage
```
